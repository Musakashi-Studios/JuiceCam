# Issues

Use the [JuiceCam issue tracker](https://github.com/Musakashi-Studios/JuiceCam/issues) for bug reports, setup questions, and feature requests. Search existing issues first so discussion and fixes stay together.

## Report a bug

Include as many of these details as you can:

- JuiceCam version and how you installed it (AssetLib or GitHub)
- Godot version and operating system
- Whether the problem happens in the editor, at runtime, or in an export
- Steps to reproduce the problem
- What you expected and what happened instead
- Relevant errors from Godot's Output panel
- A small reproduction project, screenshot, or short video when useful

Remove private project files, credentials, and unrelated assets before attaching a project or logs.

## Ask a question or suggest a feature

Describe what you are trying to do and where you got stuck. For a feature request, explain the problem in your game and the behavior you would like JuiceCam to provide.

You can also email [musakashi.dev@outlook.com](mailto:musakashi.dev@outlook.com).
