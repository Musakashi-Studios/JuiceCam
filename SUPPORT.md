# Support

For support, visit the [JuiceCam demo page on itch.io](https://musakashi.itch.io/juicecam) and click **Support this tool**.

For reproducible bugs or setup problems, [open a GitHub issue](https://github.com/Musakashi-Studios/JuiceCam/issues).

When reporting a bug, include:

- Godot version and operating system
- What you expected the camera to do and what happened instead
- A short reproduction scene or the smallest set of steps that triggers it
- Relevant error messages from Godot’s Output panel
- Whether the problem happens in the editor, at runtime, or both

Please remove private project assets and credentials before sharing a project or logs.
